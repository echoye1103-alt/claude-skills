# Image Reading Skill

从 **JPG / JPEG / PNG** 图片中识别文字，输出结构化纯文本，供 `resume-matcher` 等下游 Skill 或用户后续任务使用。

---

## 适用场景

- 简历、JD、合同、通知等**文档拍照或截图**
- 表格、海报、白板、聊天截图中的文字提取
- 其他 Skill（如 `resume-matcher`）在输入为图片时，**先调用本 Skill 再处理**

本 Skill 的职责是 **忠实转录可见文字**，默认不做匹配打分、不做内容改写（除非用户明确要求）。

---

## 支持的格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| JPEG | `.jpg`、`.jpeg` | 常见照片、扫描件 |
| PNG | `.png` | 常见截图、透明背景图 |

**不支持或需降级**：`.gif`、`.webp`、`.bmp`、`.heic` 等 → 请用户转换为 JPG/PNG，或提供 PDF / Word / 粘贴文本。

---

## 处理流程

### 1. 获取图片

- 用户上传附件，或提供工作区内的**绝对路径**
- 多张图片时，按用户说明的顺序处理（未说明则按文件名或对话顺序）

### 2. 读取与识别

1. 使用 **Read 工具**读取图片文件（支持视觉识别）
2. 逐区域识别全部可见文字，包括：
   - 标题、正文、列表、表格单元格
   - 页眉页脚、水印旁仍可辨的文字
   - 中英文及常见标点、数字、邮箱、电话、日期
3. **保持原文档结构**：用 Markdown 标题、列表、表格还原版式；分栏内容按从上到下、从左到右顺序排列
4. 无法确认的字符用 `[?]` 标注，**禁止猜测补全**姓名、数字、专有名词

### 3. 质量自检

识别后快速检查：

| 情况 | 处理 |
|------|------|
| 全文清晰可读 | 直接输出提取结果 |
| 局部模糊 | 输出已识别部分，并列出无法辨认的段落/字段 |
| 严重模糊、强反光、大角度倾斜、分辨率过低 | 说明原因，请用户提供更清晰图片或改用 PDF/Word/粘贴文本 |
| 图片为空白或非文档 | 如实告知，勿编造内容 |

### 4. 输出并交接

- 将提取文本交给用户，或供调用方 Skill 继续处理
- 若由 `resume-matcher` 触发：提取完成后**无需重复展示长文**，可直接进入匹配评估；若用户仅要求「识别文字」，则完整展示提取结果

---

## 输出格式

默认使用以下 Markdown 结构（可根据内容简化）：

```markdown
## 图片文字提取结果

**来源**：[文件名或「用户上传图片」]
**页数/张数**：第 1 张，共 N 张（多图时注明）

---

### 提取正文

[按原文结构整理的 Markdown 文本]

---

### 识别说明（可选）

- **不确定内容**：[列出含 [?] 的字段或段落]
- **未识别区域**：[描述模糊/遮挡部分]
- **建议**：[如需更清晰图片、补拍、换格式等，1-2 条]
```

**语言**：与图片主语言一致；中英混排保留原文，不擅自翻译。

---

## 多图处理

1. **同一文档多页**（如简历第 1–2 页）：按页码顺序拼接，用 `---` 或 `## 第 N 页` 分隔
2. **多张独立图片**：分别提取，用标题区分（如 `## 图片 1：resume_page1.jpg`）
3. 合并后检查重复页眉/页脚，避免重复粘贴相同行

---

## 与其他 Skill 协作

| 调用方 | 协作方式 |
|--------|----------|
| `resume-matcher` | 本 Skill 输出 JD/简历纯文本 → `resume-matcher` 执行六维评分 |
| `pdf-reading` / `docx` | 图片仅为输入方式之一；若用户另有 PDF/Word，优先用对应 Skill |
| 用户直接请求 | 仅输出提取文本，不自动触发简历匹配 |

---

## 注意事项

- **只提取、不臆造**：图中没有的信息不得写入结果
- **隐私**：不主动复述或扩散图片中与任务无关的敏感信息（如无关第三方手机号）
- **不替代专业 OCR 软件**：极复杂版式、手写潦草、低对比度场景应建议用户换清晰源文件
- **工具失败**：Read 无法打开文件时，说明格式或路径问题，并请用户重新上传或粘贴文本

---

## 使用示例

**用户**：「这是简历截图，帮我识别成文字。」

**本 Skill**：
1. Read 读取 `resume.png`
2. 按章节输出姓名、经历、技能等 Markdown 文本
3. 若有 `[?]` 字段，在「识别说明」中列出

**用户**：「用这张图里的 JD 和简历做匹配度分析。」

**本 Skill**：
1. 分别提取 JD 图、简历图中的文字
2. 将文本交给 `resume-matcher` 生成评估报告（无需用户二次粘贴）
